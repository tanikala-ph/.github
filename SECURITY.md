# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials,
private user data, reviewer documents, or exploit details in repository discussions.

Email `support@tanikala.ph` with the subject `[Security]` and include:

- the affected repository, feature, or endpoint;
- a concise description of the impact;
- reproducible steps or a proof of concept that does not expose real user data; and
- any suggested mitigation or disclosure deadline.

Tanikala will aim to acknowledge a complete report within five business days. Please
allow time for triage and remediation before public disclosure.

## Supported versions

Tanikala is currently pre-release. Security fixes are applied to the latest `main`
branch; older commits and unmaintained deployments are not supported.
