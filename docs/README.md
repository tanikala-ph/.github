# Tanikala engineering overview

These documents describe the shared technical shape of the Tanikala ecosystem.
They are intentionally public and omit credentials, private endpoints, user data,
and provider-specific account details.

## Documents

- [Platform architecture](architecture.md) — the UI/API boundary, product modules,
  request flows, persistence, realtime behavior, and trust boundaries.
- [Infrastructure](infrastructure.md) — local topology, production target, delivery
  pipeline, runtime constraints, and operational responsibilities.

The application repositories contain the detailed, versioned contracts and setup
instructions. When these summaries disagree with repository code or documentation,
the application repository is authoritative.

- [Tanikala API documentation](https://github.com/tanikala-ph/tanikala-api/tree/main/docs)
- [Tanikala UI documentation](https://github.com/tanikala-ph/tanikala-ui/tree/main/docs)
