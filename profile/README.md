# Tanikala

Tanikala is a connected ecosystem of technology made for Filipinos. We build
focused applications that help people connect, learn, share, and support one
another.

## The ecosystem

- **Convos** — meaningful conversations and new connections.
- **Pondo** — community support and transparent fundraising.
- **Sulat** — a moderated space for stories and expression.
- **Aral** — study tools for Philippine licensure exam preparation.

Our public engineering standards live in this organization repository. Product
source repositories remain private while the platform is under active
development.

For support, privacy, security, or partnership inquiries, email
`support@tanikala.ph`.
