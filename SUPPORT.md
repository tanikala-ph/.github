# Support

Use the repository issue forms for reproducible bugs and scoped feature requests.
Before opening an issue, check the existing issues and Tanikala Roadmap for duplicates.

Email `support@tanikala.ph` for account access, privacy requests, safety reports,
security concerns, or other matters that should not be public. Never place passwords,
tokens, government identifiers, payment details, private reviewer content, or another
person's personal data in a GitHub issue.
