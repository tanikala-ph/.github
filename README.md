# Tanikala community health files

This repository contains the default contribution and project-management files
used by repositories in the `tanikala-ph` organization.

It also publishes the organization profile, governance policy, and reusable CI
workflow templates for Python APIs and Vue applications.

Repository-specific files take precedence over these defaults. Ownership and CI
configuration remain in each application repository because they depend on that
codebase.

Questions that should not be posted publicly can be sent to
`support@tanikala.ph`.
